# Проект 2 — Учёт успеваемости

## Техническое задание заказчика
**Сложность:** средняя.

### Назначение
Создать консольную программу, которая рассчитывает средний балл по списку оценок и определяет, достигнут ли проходной балл.

### Входные данные
Одна строка с оценками от 1 до 5, разделёнными пробелами. Пример: `4 5 3 5`.

### Результат
- средний балл с точностью до двух знаков;
- сообщение `Зачёт`, если средний балл не меньше 4.5;
- сообщение `Незачёт` в остальных случаях.

### Ограничения
Список не должен быть пустым. Все оценки должны быть целыми числами от 1 до 5. Ошибочный ввод обрабатывается сообщением.

### Критерии выполнения
Среднее вычисляется корректно, порог 4.5 применяется верно, некорректные оценки отклоняются.
