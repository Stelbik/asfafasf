# Проект 1 — Конвертер температур

## Техническое задание заказчика
**Сложность:** простая.

### Назначение
Создать консольную программу для перевода температуры между градусами Цельсия и Фаренгейта.

### Входные данные
- направление: `C` (Цельсий в Фаренгейт) или `F` (Фаренгейт в Цельсий);
- температура — конечное числовое значение.

### Результат
Программа выводит преобразованную температуру с точностью до двух знаков после запятой.

### Правила
- Для `C`: `F = C * 9 / 5 + 32`.
- Для `F`: `C = (F - 32) * 5 / 9`.
- Неизвестное направление и нечисловой ввод должны обрабатываться понятным сообщением.

### Критерии выполнения
Обе формулы работают верно; некорректный ввод не вызывает аварийного завершения.
