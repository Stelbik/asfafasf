# Проект 3 — Учёт складских запасов

## Техническое задание заказчика
**Сложность:** сложная.

### Назначение
Создать консольную программу для учёта количества товаров на небольшом складе с сохранением данных между запусками.

### Функции
1. Добавить новый товар.
2. Увеличить количество уже существующего товара.
3. Продать заданное количество товара.
4. Показать список товаров и остатки.
5. Сохранить данные в JSON-файл.

### Входные данные
Команда меню, название товара и количество. Название не должно быть пустым, количество должно быть положительным целым числом.

### Бизнес-правила
- Нельзя продать отсутствующий товар.
- Нельзя продать ноль или отрицательное количество.
- Нельзя продать больше, чем есть на складе.

### Результат
Сообщение об успешной операции или понятное сообщение об отказе; актуальный список остатков.

### Критерии выполнения
Все команды работают; остаток никогда не становится отрицательным; данные сохраняются и загружаются.
